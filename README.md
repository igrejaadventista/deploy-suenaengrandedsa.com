# deploy-suenaengrandedsa.com

O container usa PHP 8.4.27 com Apache.

## Executar com Docker

Com Docker Desktop e Docker Compose instalados, execute na raiz do projeto:

```sh
docker compose up --build -d
```

Abra [http://localhost/](http://localhost/) no navegador.

Para parar o site:

```sh
docker compose down
```
